顶点编辑器 · 快速指南

Anchor：以一个顶点为中心调整大小

Anchor 会固定一个顶点，让其他顶点围绕它缩放。

1. 选择顶点并设置 Anchor

选择三个顶点，用 Shift + 单击追加选择。按 Z，然后按住 1，拖出选框框住要固定的顶点。

2. 调整大小

在视口的空白处拖动鼠标。绿色的 Anchor 保持不动。

顶点编辑器 · 快速指南

对齐：对齐三个尖端

在前视图中，三根尖刺的底部完全重叠，只有最前面和最后面的尖端向左右倾斜。将它们对齐到笔直的中间尖端，再旋转视角，查看三根大小相同、朝向一致的尖刺。

1. 选择尖端并设置对齐目标

在前视图中选择三个尖端。按 Z，再按 Shift+1，拖出选框框住中间的尖端。

2. 从前视图对齐

拖动鼠标，直到前视图中只看到一根完全重叠的尖刺。

3. 换个视角检查

将视角向上、向侧面旋转。现在能看到三根分开的尖刺，大小相同、朝向一致；尖端是按照前视图对齐的。

UV 编辑器 · 快速指南

实时选择：即时操作 UV 坐标

编辑 UV 图时，可以直接在实时 3D 预览中选择一个或多个顶点，并立即修改它们的 UV 坐标。用它来分离重叠的坐标。

1. 在实时预览中选择顶点

按住 A，在实时预览的可见顶点上拖出选框。对应的 UV 坐标也会被选中。

2. 分离重叠的坐标

用 A + 单击选择另一组可见顶点。按 Ctrl+E扩展到相连的顶点，再按 M切换到移动工具。把这组 UV 坐标拖离重叠区域，对其他可见组重复操作。

自动遗骸 · 快速指南

自动遗骸：调整贴合程度

以身体为参照，调整自动生成后仍不够贴合的部分。

1. 对比贴合程度

保持身体轮廓开启。切换显示 body，对比遗骸与身体，然后关闭身体显示，以便看清各个部分。

2. 移动、拉伸和加宽

双击一个部分。拖动中心控制点来移动它，拖动端点控制点来拉伸，拖动侧面控制点来调整宽度。参照身体轮廓，逐一调整需要贴合的部分。

3. 设置高度和颜色

用高度升高或降低骨骼；本例设置为 80%。将颜色色调设为 R 225 · G 255 · B 100，得到图示效果。再次开启显示 body检查，贴合后点击创建。自动遗骸还会设置 Decay Flesh 和 Decay Bone，包括身体与遗骸的可见性。

Glow Up：添加英雄辉光

添加英雄辉光，微调地面辉光大小，然后检查效果。

1. 打开 Glow Up

在主界面点击 EMTR，然后点击 Glow Up。

2. 调整地面辉光

暂停预览。轻轻拖动地面辉光边缘，微调其大小。

3. 创建并检查

点击创建并关闭 EMTR。打开动画，选择 Stand 并点击播放。按住 Alt 拖动鼠标，在播放时检查辉光。

EMTR：挥动时出现的飘带

添加贴合武器的飘带，并控制攻击中显示拖尾的时间段。

1. 创建贴合的飘带

选中武器面后，打开 EMTR 并点击添加丝带。在扫掠中选择火焰。在可见性中只勾选攻击动画，然后点击创建。

2. 设置蓝色菱形和拖尾寿命

点击持续时间旁的 + 延长拖尾。把第一个蓝色菱形拖到 20%，第二个拖到 100%。

3. 检查完整动画

点击播放，用 Alt + LMB 转动视图。未勾选的动画保持干净。

更长的拖尾
持续时间决定拖尾片段保留多久。

逐个动画设置
为每个显示飘带的动画重复设置时机。

OptimizeXL：逐项检查改动

清理数据、减小文件时，确认模型的外观和动作仍符合预期。只保留已经检查过的改动。

点击绿色标记指出的 OPXL 按钮，或按 O。

1. 对比原始模型和预览结果

之前 始终保留原始模型。之后 显示已批准改动和当前方案。选择 动画，按 Space 播放，再旋转、缩放：两侧会同步变化。

2. 谨慎精简

先检查结构修复。在 重复数据 和 动画优化 中，从较低 强度 开始逐步增加。打开 待审查多边形组 或 已更改的动画，仔细检查受影响细节，再点 批准。

Insanity FIxer

检查结构并提出可用修复。可选择一项结果或一组修复；部分需要选择方案或手动编辑。

检查受影响的动画或特效。全部修复按默认选项批量预览，仍需批准。报告无问题不代表所有动画都正常。

重复数据

合并兼容的重复顶点数据、骨骼组和等效末端骨骼，并删除符合条件的重复三角形。不会合并不同多边形组。

放大检查小开口、重叠表面、硬边和纹理细节。强度越高，允许差异越大。

动画优化

删除多余动画关键帧。更高强度允许更大差异。默认使用局部轨道；世界空间限制按容差比较变形网格。

查看所有相关动画：细微动作、武器尖端、关节、循环和死亡腐烂过渡。原定动作被改变时，降低强度。

3. 检查动作、可见性和选取范围

慢速播放并逐帧查看，检查细微动作、纹理和特效，也要查看修复片段前后。如果动作原本就应如此，使用 跳过修复。在 Sphereomancer 中，从多个角度检查碰撞球。

未使用数据

删除未被三角形使用的顶点、未引用资源和未使用骨架节点。仅在某个动画中隐藏的几何体，不会自动视为无用。

查看待删除数据，随后检查材质、纹理和特效。剩余提示可能需要单独处理。

异常修复器

针对可疑可见性、姿势不一致、抖动、突变和变形提出修复。选择结果会跳到对应动画和帧。

特殊动作可能是有意设计的。橙色、红色表示检查优先级，并非确定有错。仅供检查的结果没有自动修复。破坏预期动作的修复应跳过。

Sphereomancer

调整用于点击选取模型的碰撞球。选择预设和大小，或在高级模式中逐个编辑。

从多个角度检查覆盖范围。大小改变选取范围，而非可见几何体。批准后会替换现有碰撞形状。

Nuclear Polygon Destroyer

一个纯粹图一乐的荒唐工具。不断减少三角形，结果可能成为面目全非的实验。

单独试验后跳过阶段，避免影响正常清理。检查轮廓、孔洞、纹理和运动关节。保护可能阻止达到目标面数。

4. 只保留需要的结果

批准 在 OptimizeXL 中保留方案。返回 撤销上一次批准或跳过阶段。应用 把已批准改动送回编辑器但不保存；保存 写入文件。未批准预览不会被包含。

批准前仔细检查

形状与纹理
放大并旋转，检查开口、薄片、硬边、纹理接缝和重叠层。

动作与可见性
以正常和慢速查看完整循环及过渡，留意丢失的细微动作、新增突跳、漂浮部件、特效变化和错误时机出现的物体。

文件大小不能说明一切
若较大文件保留了预期外观和动作，就保留它。结果变差时，降低强度、跳过方案或返回撤销。

最后检查
保存前检查所有相关动画。报告无问题或编辑器预览正常，本身并不能验证模型在 Warcraft III 中的表现。

FX · QUICK GUIDE

FX：制作特效

FX 为模型的一个部分添加在所有动画中运行的永久特效。本教程逐个部分为大不净者覆盖冰效果；每一步都接着上一步继续。

1. 皮肤上的冰

打开 FX。用鼠标左键旋转预览，然后双击皮肤。打开 冰 并点击 冰霜。在 变化 上滚动鼠标滚轮选择一个版本，这里是 霜覆钢铁。应用特效 会将其添加到模型。

2. 脓疱上的水晶

再次打开 FX；皮肤保留其特效。转到背面并双击脓疱。点击 冰 > 水晶，在 变化 中选择 水晶生长。选中 水晶 图层后，拖动 大小、长度、数量 和 辉光。应用特效。

3. 角上的冰

双击一只角，选择 冰 > 冰霜，变化 选 深色冰面。取消勾选 下落薄雾 以关闭该图层。点击 添加图层，输入 冰晶切面 并点击该行。应用特效。

4. 武器上的冰刺

双击刀刃，点击 适应选择 将其放大。选择 冰 > 冰霜，变化 选 冰刺。点击 冰刺 图层并拖动 大小、数量 和 长度。应用特效。

5. 挥击上的冰霜扫掠

在 顶点 中，点击 几何集 下的 清除，勾选刀刃的几何组，然后按 Ctrl + A。打开 发射器编辑器 并点击 添加丝带。在 扫掠 中选择 冰霜，在 可见性 中勾选攻击动画，然后点击 创建。

6. 查看结果

打开 展示。点击列表中的动画，选择 Attack - 1，点击 确定，然后点击 预览动画。用鼠标滚轮缩放，用鼠标左键旋转镜头。

UV WRAPPER · QUICK GUIDE

UV 网格与吸附

对齐色孽骑士马披布上的图案。开始时，UV 编辑器中的披布几何体应已选中。

1. 设置网格

开启网格。调整大小，或在设置 → 间距中输入精确值。开启吸附。

2. 吸附单个顶点

选择移动，拖动一个已选中的 UV 顶点。拖动时，顶点会自动吸附到网格交点。

3. 按网格移动一组顶点

保持网格和吸附开启。使用数字小键盘一起移动选中的 UV 顶点：每按一次，各活动轴都移动当前网格的一格。斜向移动时，两条轴各移动一格。按三次 6 即向右移动三格；顶点之间的相对间距保持不变。

顶点编辑器

分合部件

将色孽战士的两把武器拉近或拉开，同时保持原尺寸。先在顶点编辑器中选中两把武器。

1. 用调整大小工具缩小武器

按 Z 选择调整大小工具，然后向左拖动。两把武器会缩到同一点。按 Ctrl + Z 撤销。

2. 保持原尺寸并拢武器

开始拖动后按住 Ctrl。向左拖动，让两把武器在枢轴处汇合，再向右拖动将它们分开。松开鼠标前一直按住 Ctrl。

工具按连通的网格分组。录制时，在模型副本中将每把武器的网格连接成一个部件。

顶点编辑器

动画预览

动画预览在编辑时以模型某个动画的一帧显示模型。编辑会改变基础姿势，所有动画都会使用这些修改。

1. 选择动画和帧

点击动画预览旁的箭头并选择动画。动画预览会在该动画的第一帧开启。右键单击动画预览，输入帧编号并按 Enter。Shift + Space 在该帧和基础姿势之间切换。

2. 在摆好姿势的模型上编辑

在帧中看到顶点的位置直接选择并移动：按 A 拖出选框，再按 M 拖动。按 Shift + Space 可在基础姿势中看到同样的修改。

工作平面约束

每一块

每一块位于顶点编辑器中工作平面约束旁边。Forge 中也有同样的复选框。

开启和关闭“每一块”时旋转

关闭：旋转（R）把整个选区作为一组旋转。开启：每个单独的块在原位旋转。视频中先旋转整个 Footman（Ctrl + A），用 Ctrl + Z 撤销，再在开启每一块后旋转。

锻造

调用 Forge 工具

调用 Forge 工具会把 Forge 工具加入顶点编辑器。这里为 Footman 的盾牌倒角，并把它弯成弧形盾。

1. 调用 Forge 工具

右键单击锻造图标并选择调用 Forge 工具。Forge 工具会在顶点编辑器左侧打开。选择、镜头、撤销和其他顶点工具照常可用。

2. 单独显示盾牌

红色队伍颜色层是单独的几何集：在几何集下勾选 2。按 A，点击一个盾牌顶点，再用 Shift + LMB 点击其余顶点。点击分离为新多边形组，再点击清除，勾选这两个新几何集并关闭显示全部：只显示盾牌。

3. 倒角

在视图菜单中选择左视图和线框。取消勾选红色层，按 Ctrl + A 选中盾牌。点击倒角并拖动金色手柄：轮廓上出现新的边。点击 ✓ 保留。

4. 弯曲

选择透视图和纹理视图，重新勾选红色层并按 Ctrl + A。点击弯曲，选择横向和转动弯曲，使盾牌沿深度方向弯曲，然后拖动手柄：两侧向身体弯去。点击 ✓。重新打开显示全部并点击适应，查看整个 Footman。

5. 检查

用 Alt + LMB 转动视图。Ctrl + Z 和 Ctrl + Y 撤销和重做弯曲。

运动

聚焦骨架

聚焦骨架只显示所选部位的骨骼，因此骨骼和骨架可以保持关闭。

1. 双击部位

在肢体上 LMB × 2 会选中它的骨骼并开启聚焦骨架。再双击另一个肢体即可转移焦点。

2. 为该部位做动画

点击时间轴上的一帧，在工作平面中选择 YZ，然后 R + LMB 并拖动。Space 播放。

运动

POSE

POSE为手、脚和身体添加控制点。

1. 开启 POSE

点击时间轴上的一帧，然后点击工具中的 POSE。

2. 摆放手臂

拖动手控制点来摆放手臂。

3. 身体和脚

把身体向下拖，把脚向前拖。Alt + LMB 转动视图。

UV 编辑器

适应

适应位于 UV Wrapper 工具中。自由套索和魔棒同样可以标出区域。

标出区域

选中点，点击适应，再用多边形套索依次点击纹理某一部分周围的各个角。按 Enter 闭合。

适应

再次点击适应：选中的 UV 移入该区域。只移动已有的点。

顶点编辑器

切割

切割位于顶点编辑器中的创建三角形旁边。

切割线

点击切割，再点击一个顶点。移到它对面的线上并点击：在该处生成一个点，线两侧的两个三角形都被分割。

切割到角

按 Ctrl + Z 撤销。保持切割开启，点击一个顶点，再点击线对面的角：两个三角形之间的线转向并终止于该角。
